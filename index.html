⚡ Week 1 Quick Reference Card
Command Plain English Meaning Example / Common Use
pwd "Where am I right now?" Prints current directory path
ls -la "Show me everything here" Lists all files, permissions, and hidden dotfiles
cd <folder> "Go inside this folder" cd /var/log (or cd .. to go up one level)
tail -f <file> "Stream logs live" tail -f /var/log/bad.log (Exit with Ctrl + C)
lsof <file> "Who is using this file right now?" lsof /var/log/bad.log (finds the process ID / PID)
kill <PID> "Force stop this program" kill 595 (no brackets!)
grep "keyword" <file> "Search inside this file for text" grep "ERROR" server.log
